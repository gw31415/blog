## 文書の保守

- 概要と最初の起動手順はルートの [README](../README.md)、作業ルールは [AGENTS.md](../AGENTS.md)、具体的なスキルは `.agents/skills/` に置きます。
- 本文・メタデータ・編集操作の意味を変えるときは、[文書仕様](tiptap-document-spec-v1.md) を先に更新します。実装の対応箇所は [アーキテクチャ](architecture.md) を参照してください。
- コマンドは `package.json`、環境の違いは `vite.config.ts` と `cloudflare.config.ts` に合わせて更新します。本番のデータ件数、ログイン結果、デプロイ済みという一時的な確認結果は、恒久的な設定説明と混ぜません。
- `archive/` は当時の記録です。古い依存関係・パス・未チェックの手順を、現在の作業指示や実装状況として使いません。
