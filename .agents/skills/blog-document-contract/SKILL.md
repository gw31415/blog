# 文書仕様を先に変更する

正本は [tiptap-document-spec-v2.md](../../../tiptap-document-spec-v2.md)。変更対象の節と第13章の実名・既定値対応を読み、データ構造や意味を変える場合は、まずこの文書を編集してから実装する。通常の実装依頼について再承認を求めない。

- 本文の正本はTiptap JSON。通常保存・再読込にMarkdownの往復を挟まない。
- 未知ノード・属性や未確定入力を黙って削除しない。診断と元入力を保持する。
- ノード・マーク・属性の変更は正規化、Markdown入出力、SSR、編集操作、サンプルの該当箇所へ反映する。意味が変わる場合はスキーマ版と既存データの扱いも仕様に記す。
- MathJax/Mermaidのサポート内容は使用版の公式資料で確認し、描画仕様を更新する。変換ライブラリやコンポーネント種類を便宜的に置き換えない。
- JSON保持、Markdown往復、実画面操作を区別して必要な確認を行い、未確認を成功と報告しない。
- 今回の初期化を一般化してデータを破棄しない。今後の破棄はユーザーの明示した範囲に限る。

- 文書対応に便乗して目次、記事設定、書き出しメニュー、常設取り込みUIを追加しない。タグ等の直接編集は既存DOM位置を保ち、説明の編集UIは提供しない。Markdown出力は仕様書13.2のURL契約に従う。

- 数式・Mermaidの描画設定やライブラリ版を変えるときは `src/content/render-contract.ts` の描画契約識別子も更新する。共通キャッシュは時間TTLを持たず、ソース参照で維持する。SVGアップロードは記事保存の編集権限を通し、クライアントHTMLを直接本文へ展開しない。
