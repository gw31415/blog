朝、窓の端に細い光が差していた。昨夜閉じたままの本を開く前に、机の上を少しだけ片付ける。湯を沸かしている数分間は、仕事の予定よりも先に、昨日の続きを思い出す時間になる。

ノートには「よく見たもの」を一行ずつ書く。雲の形、珈琲の温度、電車の音。大きな出来事がない日ほど、あとで読み返せる小さな目印が必要なのだと思う。

## 光と行間

窓辺の明るさは刻々と変わる。写真のように正確には残せなくても、時刻 $t$ と明るさ $E(t)$ を並べると、その変化の輪郭だけはつかめる。朝の三回の観測値を $E_1,E_2,E_3$ としたとき、平均は次のようになる。

$$
\overline{E}=\frac{E_1+E_2+E_3}{3}
$$

今日は数値そのものより、**三度とも違う色に見えた**ことの方を覚えておきたい。均一に並んだ方眼の上でも、書く文字の長さや余白は毎回違う。

| 時刻 | 窓辺 | ノートに残したこと |
| --- | --- | --- |
| 06:40 | 青みのある薄い光 | 本の影がまだ長い |
| 07:10 | やわらかい金色 | カップの縁が明るい |
| 07:35 | 白に近い光 | 机の木目が見えた |

## 方眼を使う理由

同じ幅の罫線があると、短い語も長い文章も一度受け止めてもらえる。線に合わせてすべてをきっちり書く必要はない。むしろ少しはみ出した文字を見ると、そのとき急いでいたか、ゆっくり考えていたかまで思い出せる。

画面上のノートでも、行高と方眼の間隔には関係がある。本文の文字サイズを $f$、行高倍率を $\lambda$ とすれば、一行の高さは $L=f\lambda$ だ。数字を決めるより先に、文章が窮屈に見えないかを確かめる。

```css 方眼と本文
.note {
  font-size: 15px;
  line-height: 1.5;
  text-autospace: normal;
}

.note p + p {
  margin-block-start: 1.5em;
}
```

この短い CSS は表示の説明であり、朝の景色そのものを表すものではない。ただ、書き留めた言葉に十分な空間を与えるための道具にはなる。文字の間隔が気になるときは [MDN の text-autospace の説明](https://developer.mozilla.org/en-US/docs/Web/CSS/text-autospace) に戻って確かめたい。

> 記録は一日を全部保存するためではなく、あとでその日へ戻るための入り口になる。

### 文章を置く場所

このページでは本文と図版の間に、少し広い余白を取る。段落の長さをそろえるより、読みながら一息つける場所を作る方が大切だ。コードも同じ本文の一部として置くと、記録した時刻を機械にも読める形で残せる。

```html 朝の観測
<figure class="morning-note">
  <time datetime="2026-09-23T07:10">七時十分</time>
  <figcaption>窓辺の光が金色に変わった。</figcaption>
</figure>
```

短い見出しと長い行が交互に現れても読みやすいかを確かめるため、あえて幅の違う要素を並べている。箇条書きもその一つだ。

- 窓を開けて空気の温度を確かめる
- 今日の日付を手で書く
- 気になった言葉に線を引く

## 午後の頁

午後には朝の表を閉じ、窓の外をもう一度見た。午前と同じ位置にカップを置いても、影は反対側へ伸びている。朝に書いた数値をそのまま並べるだけでは、一日の変化を表せない。

明るさを時刻に沿って積み重ねるなら、概念としては次の面積を考えられる。実際のノートには測定器がないので、これは計算結果ではなく、変化を想像するための式だ。

$$
S=\int_{t_0}^{t_1} E(t)\,dt
$$

窓の向こうでは雲が流れ、光は途中で何度も弱くなった。均一な方眼も、こうした揺れを消すためのものではない。むしろ揺れを見逃さず、別の日と比べるための静かな背景になる。

ノートを読み返して、朝の「白に近い光」に下線を引いた。正しい名前を付けるより、**もう一度そこを見たくなる言葉**を残す方が、自分には向いている。

## 昼に読み返して

午前の終わりにノートを開くと、「金色」と書いた箇所で少し迷った。光の色を正しく名付けたわけではないし、別の日なら「薄い黄色」と書いたかもしれない。それでも、その曖昧な一語から、湯が沸く前の静けさが戻ってきた。

観測を重ねれば、明るさの曲線を描くこともできる。けれども今日はグラフを完成させない。夕方の頁にも書く場所を残しておく方が、このノートには合っている。

書き終えるころには湯が沸いていた。読みかけの本を開く前に、ノートを一度閉じる。**今日の朝は、もう昨日の朝とは別のものになった。**
